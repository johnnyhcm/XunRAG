# PRD 线框图（v3 — ChatGPT / 豆包风格）

> 原则：对话是首页唯一主角；政策浏览/管理/设置收进顶部栏或抽屉，不抢注意力。

---

## 全局布局

```
┌──────────────────────────────────────────────────────┐
│ ☰ ≡ 企业政策 AI                        [浏览政策] [⚙] │  ← 最小顶部栏
├──────────────────────────────────────────────────────┤
│                                                       │
│                    对话区域                            │
│                 （最大宽 800px 居中）                    │
│                                                       │
│                                                       │
│              ┌──────────────────────┐                 │
│              │  输入问题…     [发送] │                 │
│              └──────────────────────┘                 │
└──────────────────────────────────────────────────────┘
```

- **☰**：展开历史对话侧边栏（左侧滑出，覆盖式）
- **浏览政策**：打开政策浏览侧边栏（右侧滑出，抽屉式）
- **⚙**：设置（下拉菜单：AI 状态 / 政策管理入口 / 未来更多）
